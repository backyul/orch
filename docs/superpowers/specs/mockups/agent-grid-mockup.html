agent·grid — cockpit mockup spec: GUI-driven lifecycle (replaces orc-start)
spec: Import = resume a saved team/member (vs spawn = new)
How to read this mockup. Each box is one Claude Code agent in its own PTY (replacing a psmux pane). Click a pane to focus · ⤢ zoom · ↻ restart · ✕ kill · + Add agent spawns one. Open ⚙ Settings to connect Claude, set the Telegram bot token, switch layout (tiled ↔ free drag/resize) and theme (Dark ↔ Claude) — the theme switch is live, try it. Blue/clay tags pin UI to spec decisions.

⚙ Settings

Claude account

Claude Code signs in through your Claude subscription — no password is stored here.

Not connected

Opens the official Claude sign-in in your browser (OAuth). The claude CLI holds the token.

Telegram bot

Drives the away/escalation notifications. Saved to the gitignored .env, never committed.

Appearance — Layout

Tiled auto-arranges every pane; Free lets you drag panes by their header and resize from the corner.

Appearance — Theme

Switches the whole cockpit, terminals included. (Live — changes apply instantly.)

🎭 Persona —

Injected as claude --append-system-prompt when the agent launches. Saving restarts the agent to apply it (its memory survives via --resume).
